# ADR: Backend platform

Status: Accepted for MVP baseline

+## Context

The API needs typed HTTP boundaries and a Python ecosystem compatible with future AI work.

## Decision

Use FastAPI with Python, dependency injection seams, and modular domain packages.

## Consequences

Good async/API ergonomics and a direct path to future AI orchestration.

## Alternatives considered

A Node-only backend; a heavier framework before requirements exist.
