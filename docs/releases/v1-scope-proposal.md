# PrüfAI V1 scope proposal

**Product signoff pending. Pilot launch authorization pending. Production readiness has not been established.**

Propose a **non-official Berlin Leben in Deutschland (LiD) practice pilot** for a bounded candidate cohort and an institution. A candidate takes an approved Berlin practice attempt, an institution reviews the objective result, and an authorized person explicitly releases it. The Control Centre supports oversight of the approved source, exam version, access and audit evidence. Product signoff selects this scope. A separate pilot launch decision requires the applicable gates in the [readiness register](v1-readiness-register.md).

| Included in the proposal | Release condition |
| --- | --- |
| Candidate sign-in and assignment | An authorized institution uses an approved invitation or staff-assisted enrollment flow. Verify acceptance, identity, support and recovery with real users after privacy and environment approval. |
| Berlin practice exam | Use original, independently reviewed Berlin items in a versioned practice form. Candidates can prepare, start the timed attempt, save, resume and submit. Candidate screens identify the experience as practice. |
| Institution examination workflow | An authorized examiner reviews the objective result and exact attempt and score versions. A permitted actor explicitly releases or revokes the practice result. The candidate sees their own released result only. |
| Control Centre governance | Authorized operators inspect source and rights evidence, practice exam version, role boundaries and relevant audit events. Editorial mutations use the approved workflow and environment. |
| Basic service support | Provide candidate and examiner help, an accessible recovery path and an accountable support contact during the authorized pilot window. |

**Default exclusions.** Official certificates or exam claims, nationwide LiD coverage, autonomous AI scoring, A1–C2 assessment claims, CEFR B1 or DTZ assessment delivery, Writing/Speaking assessment delivery, candidate audio processing and unapproved external AI providers. Technical features outside this boundary may remain available in disposable development. The pilot entry points, flags and permissions must enforce the approved scope before participants enter. The pilot provides a practice result only and makes no claim of official equivalence or credential eligibility.
