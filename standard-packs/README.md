# Standard Packs

This directory contains schemas and synthetic fixtures only. It does not contain
provider PDFs, official questions, copied instructions, or production-approved
pack configuration. Production Standard Pack versions are database-managed,
source-bound, reviewed, and published through the platform APIs.

Synthetic governance fixtures are under `fixtures/` and are explicitly marked
`TEST FIXTURE — NOT OFFICIAL STANDARD`.

Standard Packs will eventually contain versioned, machine-readable examination configuration and source bindings for approved standards and providers.

The placeholders in this directory do not contain examination questions or copyrighted provider material. Copied provider examination content must not be added unless PrüfAI has explicit rights to store and use it.
